# MyBirthday22 — Interactive Personal Portfolio & Lab

Bienvenido/a a **MyBirthday22**, un repositorio personal interactivo concebido como un recorrido modular de 22 experiencias web, experimentos visuales, simuladores y mini-aplicaciones. Este proyecto celebra la intersección entre el código, la música, la literatura, la matemática, la ciberseguridad, el arte visual y la cultura pop asiática.


## La Nave Central (Hub Principal)

El proyecto está articulado mediante **La Nave Central (`index.html`)**, una interfaz de control con estética de *Cyber-Dashboard / OS Futurista* desde la cual se puede monitorear, filtrar y lanzar cada uno de los módulos activos.

- **Tecnologías:** HTML5, CSS3 Custom Properties, JavaScript Vanilla (ES6+), Canvas API, Web Fonts.
- **Asistente Integrado:** `Jelly` (Widget flotante interactivo de guía).

## Ejecución Local
1. Clona el repositorio:
```bash
git clone [https://github.com/tu-usuario/MyBirthday22.git](https://github.com/tu-usuario/MyBirthday22.git) 
```

2. Navega al directorio raíz:
```Bash
cd MyBirthday22
```

3. Abre index.html en tu navegador o ejecuta un servidor local (como Live Server en VS Code):

```Bash
npx serve . 
```

## Principios de Diseño
- Zero Heavy Frameworks: Construido puramente en Vanilla
HTML/CSS/JS para máximo rendimiento y portabilidad.

- Diseño Temático & Inmersivo: Cada módulo adapta su propia paleta cromática, tipografías e interacciones según su temática (Cyberpunk, Scrapbook, Vintage, Gothic, Pixel Art).

- Diseño Responsivo: Adaptado para consumo tanto en escritorios como en dispositivos móviles.
